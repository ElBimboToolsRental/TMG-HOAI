# TMGHOAI Website

GitHub/AWS-ready static website for The Mango Grove Homeowners Association, Inc.

## Included files

- `index.html`
- `style.css`
- `images/logo.png`
- `README.md`

## GitHub Pages Upload

1. Create a GitHub repository.
2. Upload all files and folders from this ZIP.
3. Go to Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main.
6. Folder: /root.
7. Save.

## AWS S3 Static Website Upload

1. Create an S3 bucket.
2. Upload all files and the `images` folder.
3. Enable static website hosting.
4. Set index document to `index.html`.
5. Configure public access or CloudFront.
